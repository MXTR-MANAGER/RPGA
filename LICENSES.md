# Лицензии и авторство

RP-MXTR-RPGA использует сторонние 3D-модели в качестве референсов и ассетов.
Ниже указаны авторы и лицензии найденных моделей (OpenGameArt).

| Модель | Автор | Ссылка |
|---|---|---|
| Retro Style Pistol Lowpoly (пистолет) | Mohamkey | https://opengameart.org/content/retro-style-pistol-lowpoly |
| M9 Knife PBR (нож) | khairul169 | https://opengameart.org/content/m9-knife-pbr |
| Mk2 Grenade (граната) | LonesomeDucky | https://opengameart.org/content/mk2-grenade |
| Radio (рация) | yethiel | https://opengameart.org/content/radio |
| Five Tools CC0 (отвёртка) | yd | https://opengameart.org/content/five-tools-cc0 |
| 3d Keycard (ключ-карта) | codeinfernogames | https://opengameart.org/content/3d-keycard |

## Не используются из-за лицензий
Следующие модели не вошли в сборку, так как их лицензии (CC-BY-SA / GPL) несовместимы:
C4 Charge, Small Explosives Pack (без текстур/развёртки), Handcuffs, Tonfa.
Вместо них используются собственные JSON-модели (blockbench-подобные элементы) с текстурами из игры.
