## 🆕 Что нового в 30.0.1

### 🌐 Приложение «Даркнет»

В смартфоне появилось **новое приложение — «Даркнет»**. Раньше смартфон
был просто предметом без наполнения, теперь у него появилось первое
полноценное приложение с интерфейсом.

| Что появилось | Назначение |
|---|---|
| 🌑 **Экран «Даркнет»** | Отдельное приложение-экран внутри смартфона |
| 🔄 **Синхронизация состояния** | Пакет `darknet_sync` — сервер передаёт клиенту актуальное состояние |

| Поле | Описание |
|---|---|
| 🎯 **Разыскивается** | Признак того, что персонаж в розыске |
| ⏱ **Таймер** | Обратный отсчёт состояния |
| 🔃 **Обновление** | Синхронизация изменений с сервером |

### 🧩 Технически

| Класс | Назначение |
|---|---|
| `DarknetScreen` | Экран приложения «Даркнет» (наследует базовый экран приложений смартфона) |
| `RPGAPayloads$DarknetSyncPayload` | Сетевой пакет синхронизации состояния даркнета |

Класс экрана наследуется от общего базового класса приложений телефона,
поэтому «Даркнет» открывается так же, как и остальные приложения смартфона,
а его состояние приходит с сервера отдельным пакетом.

## 🔒 Почему именно эта версия

> 🌐 **Версия 30.0.1 используется на сервере RPGA.**
> Это не экспериментальная сборка — это рабочая версия сервера,
> проверенная в реальной эксплуатации.

| Преимущество | Пояснение |
|---|---|
| 🔐 **Серверный источник истины** | Состояние «Даркнета» приходит с сервера пакетом `darknet_sync`, клиент его только отображает |
| 🕵️ **Надёжность для спецопользования** | Признак «в розыске» и таймер нельзя подделать на клиенте — они считаются на сервере |
| 🔄 **Синхронизация** | Изменения статуса применяются у всех участников сразу, без рассинхрона |
| 🧱 **Минимальный риск** | Сборка не содержит тяжёлых подсистем 30.0.2 (тюрьма, замки, дым) — меньше поверхность для ошибок |

> 💡 Для спецслужб и оперативных сценариев на сервере RPGA рекомендуется
> именно **30.0.1**: «Даркнет» в этой версии работает с серверным состоянием
> и потому надёжнее, чем в клиентских сборках.
